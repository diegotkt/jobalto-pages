📦 partage-skill-equipe

Publie ta skill perso vers le repo équipe via PR

Créée par Diego — @diegotkt

🎯 Le but

Promouvoir une skill Claude personnelle (créée dans ~/.claude/skills/) vers le repo équipe Jobalto/jobalto-team-repo, proprement et sans connaître git : checklist qualité, clone, branche, plugin.json, mise à jour du README (avec ton nom en créateur !) et ouverture de la Pull Request.

👥 Qui l'utilise, et quand

Pour tout collaborateur dont une skill perso marche bien :

  • Tu as créé une skill, elle tourne, tu veux la diffuser à toute l'équipe.
  • Tu dis « ma skill est prête, je veux la partager » — Claude fait le reste.
  • La checklist qualité bloque les secrets (tokens, IBAN, NISS) avant publication.

📤 Output attendu

Une Pull Request complète sur le repo équipe :

  • Skill copiée dans skills/, plugin.json versionné, README à jour.
  • PR ouverte avec description et reviewer (Diego) assigné.
  • Après merge : la skill est dispo automatiquement pour toute l'équipe.

Output type

Aperçu illustratif du livrable produit par la skill.
